# Historical PGAT LIANA reference files

These unchanged CSVs were recovered from the local figure-data archive on
2026-11-05. Source names and hashes are in `provenance.json`. They are derived
interaction outputs, not raw single-cell objects or new analyses. They contain
per-age interaction records and are distinct from the secondary pooled-age
scores in `../results/cci/`.

They provide the historical CCI reference used for contextual comparisons;
they do not supply the hard-coded VEC rho/P targets or an equivalence margin
for the old female-zero expression targets. Those provenance limits remain.
No numerical replication or mouse-level uncertainty is inferred from these
reference files.
